## 四个维度怎么判

1. **Hook（开篇抓力）**：{{hook_definition}}
   只看开头。问题是否快速建立？冲突 / 悬念是否尽早出现？前几段有没有明确的抓力？读者有没有理由继续读下去？

2. **Pacing（节奏）**：{{pacing_definition}}
   只看阅读速度与拖沓感。推进速度如何？信息密度够不够？有没有重复的段落、场景或台词？高潮前是否过慢？高潮后是否收束过久？

3. **Engagement（全篇持续阅读动力）**：{{engagement_definition}}
   只看全篇，不看开头。悬念是否持续？冲突是否维持？场景之间是否持续提供新信息？读到哪里容易中途失去兴趣？

4. **Payoff（回报）**：{{payoff_definition}}
   只看承诺与兑现。前文给出的承诺是否得到回报？高潮是否有足够价值？结尾是否回应了主要冲突？关键悬念是否得到基本兑现？

### 维度边界（必须分清，不要混为一谈）

- Hook ≠ Engagement：Hook 是**开头**的抓力，Engagement 是**全篇**的持续阅读动力。开头抓人但中段崩塌，是 Hook 高、Engagement 低。
- Pacing ≠ Narrative：Pacing 是**阅读速度与拖沓感**，Narrative 是故事结构和推进是否成立。结构成立但读起来拖沓，是 Pacing 低。

## 输出要求

只输出一个 JSON 对象，不要 markdown 代码块，不要任何解释文字。字段如下：

{
  "score": 0,
  "summary": "一段话说清这篇小说的商业可读性整体表现",
  "strengths": ["商业可读性上的优点"],
  "problems": ["商业可读性上的问题"],
  "suggestions": ["可以怎么改的建议"],
  "dimensions": {
    "hook": { "score": 0, "summary": "开篇抓力的一句话评价" },
    "pacing": { "score": 0, "summary": "节奏的一句话评价" },
    "engagement": { "score": 0, "summary": "全篇持续阅读动力的一句话评价" },
    "payoff": { "score": 0, "summary": "回报的一句话评价" }
  }
}

规则：

- 四个维度一个都不能少，也不许多出别的维度
- 每个维度分是 0 ~ 100 的整数或小数，短评不能为空
- strengths / problems / suggestions 都必须是字符串数组（可以为空数组）
- score 必须与四个维度一致：它就是四个维度的均分
- 只描述文本本身可观察的事实，不要预测市场、销量、读者规模或商业结果
- 不要用"必火""爆款""签约概率""市场成功率"一类说法
